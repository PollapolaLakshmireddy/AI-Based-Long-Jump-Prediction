# Long Jump AI

AI-based Long Jump Talent Identification and Performance Analysis.

## Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js, REST API
- Database: PostgreSQL
- ML: Python, Pandas, NumPy, Scikit-learn
- Computer Vision: OpenCV / MediaPipe (planned)

## Structure
Frontend -> Express REST API -> PostgreSQL / Python ML service

## Getting started
1. Install Node.js, PostgreSQL, and Python.
2. Configure `.env` using `.env.example`.
3. Run `npm install` inside `backend`.
4. Set up the PostgreSQL schema from `database/schema.sql`.
5. Install Python packages from `ml/requirements.txt` when starting ML work.
